Déploiement d’un site web statique sur AWS avec CI/CD (S3 + CloudFront)

Un site web statique hébergé dans un bucket S3 privé, diffusé par CloudFront en HTTPS et mis en ligne automatiquement par un pipeline CI/CD.

Contexte et objectifs

Un portfolio doit être rapide, peu coûteux et fiable. Un site statique répond à ces trois besoins sans serveur à maintenir. J’ai voulu en faire aussi une démonstration : l’hébergement lui-même illustre les bonnes pratiques AWS que je présente dans mes autres projets.

  • Servir le site en HTTPS sur un domaine personnalisé.
  • Garder le bucket S3 entièrement privé.
  • Mettre en ligne une modification en moins de cinq minutes après un push.
  • Maintenir un coût mensuel de quelques dollars.
  • Pouvoir recréer toute l’infrastructure à partir du code.

Architecture

Le visiteur résout le domaine avec Route 53, qui renvoie vers CloudFront. CloudFront termine la connexion HTTPS avec un certificat ACM, sert le contenu depuis son cache et ne contacte S3 que si l’objet est absent. Une CloudFront Function réécrit les adresses de répertoire : /projets/ devient /projets/index.html.

L’accès à S3 passe par un Origin Access Control (OAC) : seule la distribution CloudFront est autorisée à lire les objets du bucket.

Composants associés : ACM (certificat TLS), CloudFront Function (réécriture d’adresses), OAC (accès privé à S3).

Mise en œuvre

Le bucket est créé avec le blocage d’accès public activé. La politique suivante autorise uniquement la distribution CloudFront à lire les objets.

La CloudFront Function s’exécute à chaque requête et ajoute index.html aux adresses de répertoire.

Enseignements

  • Le certificat ACM d’une distribution CloudFront doit être créé en us-east-1, quelle que soit la région du bucket.
  • Avec une origine S3 privée, les sous-répertoires ne servent pas index.html sans réécriture d’adresse.
  • Invalider le cache à chaque déploiement évite de servir du contenu périmé ; des noms de fichiers versionnés réduisent ce besoin.
  • Un budget AWS avec alerte doit exister dès le premier jour.
